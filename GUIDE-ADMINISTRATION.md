# Administrer mon portfolio

**Adresse de l'administration :** https://app.pagescms.org/hisseine-malabad/portfolio/main
**Site public :** https://hisseine-malabad.github.io/portfolio/

## Se connecter
Ouvrir l'adresse d'administration, cliquer sur « Sign in with GitHub », se connecter avec le compte `hisseine-malabad`.
Seul ce compte (ou une personne que vous inviteriez) peut modifier le site. Les visiteurs ne voient que le site public.

## Modifier une rubrique
Dans le menu de gauche, chaque rubrique du site porte son numéro (1. Accueil … 8. Contact).
Ouvrir la rubrique, modifier le texte, puis cliquer sur **Save** (Enregistrer).
Le site public se met à jour automatiquement en une à deux minutes. Recharger la page du site pour voir le changement.

## Ajouter un mémoire ou un article
Menu « 4. Recherches — mémoires et articles » → **Add an entry**.
Remplir le titre, choisir la catégorie (« Mémoire universitaire » ou « Article »), écrire le résumé,
puis joindre le PDF et, si vous le souhaitez, la version Word. Enregistrer.
Pour le retirer du site sans le supprimer : décocher « Afficher sur le site ».

## Mettre à jour le CV ou un document
Menu « 5. Documents » : chaque document a un titre, une catégorie et un fichier.
Pour remplacer un fichier, cliquer sur le champ « Fichier » et téléverser le nouveau document.
Penser à mettre aussi à jour le CV dans « 8. Contact » s'il a changé de nom.
Un fichier Word reste un fichier Word : le site l'indique comme tel. Pour proposer un PDF, exportez-le d'abord depuis Word (Fichier → Enregistrer sous → PDF).

## Changer la photo
« 1. Accueil » → champ « Photographie de profil » → téléverser la nouvelle image.

## Ajouter ou retirer une rubrique
- Rubrique nouvelle : « Rubriques supplémentaires » → ajouter un élément (titre, texte, document éventuel).
- Masquer une rubrique existante : décocher « Afficher cette rubrique ».

## Attention
Tout ce qui est publié est public, y compris le contenu des PDF (téléphone, adresse postale du CV…).
